建议补充唯一文件：`Phase5c_GEE_Full_Matched_Movement_Data.csv`（如果保留了每段起终点坐标、U/V与全部原GPS字段），以及`Phase5a_Frozen_Movement_Data.csv`或可验证的冻结manifest，用于只读验证。

有了完整字段，先进行**变量审计，不拟合生态模型**：

1. 逐段核对ID、Bird_ID、设备、起止UTC、经纬度、U/V、距离、分组及冻结哈希。
2. 以**分析段之前**的独立历史定位构建候选参考方向（不使用分析段终点）；按鸟、阶段、昼夜统计可用率与方向误差；若位移太短或出现断档，方向留空。
3. 使用**分析段起点**U/V与历史参考方位θ，计算 `AlongWind=U*sinθ+V*cosθ`（正值顺风、负值逆风）和 `CrossWind=U*cosθ−V*sinθ`；起点比中点更适合时序上的先行天气定义。
4. 单独输出当前观察位移方向与风夹角作为**描述性暴露**，不把该段自身移动方向构建的相对风场解释成独立的、对同一段距离的因果预测量。
5. 对春迁真实长距离事件与越冬局地移动分开报告，检查方向可用子样本是否严重偏向长距离或少数鸟；若覆盖不足，停止建模。
