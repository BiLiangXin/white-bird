## 0. 一页摘要

**要回答的问题：** 越冬白额雁夜间≥1 km 的转移，是否由"当时有月光"引起？如果是，月光改变的是转移的**时机**（傍晚还是后半夜）、**去向**（是否远离白天活动区）还是**发生率**？

**核心识别思路：** 月亮每晚晚升约 50 分钟。盈月照亮傍晚、亏月照亮后半夜，而同一夜的日期、天气背景、节庆和个体状态都相同。所以，同一鸟夜内"月亮在天"与"月亮在下"的对比，可以区分**即时光照**和**月相周期**。

**模型策略：** 不靠单一模型下结论。用 9 个模型从不同角度估计同一组预先定义的效应量（第 4 节）：

| 角色 | 模型 | 回答什么 |
| --- | --- | --- |
| 主识别 | M2 鸟夜分层条件 logistic | 夜内的即时光照效应 |
| 主估计 | M1 段级层次 GLMM | 光照效应与夜内时机交互 |
| 主过程 | M3 离散时间风险模型 | 首次转移**何时**发生 |
| 剂量—反应 | M4 层次 GAM | 光照强度的非线性响应面 |
| 个体与小样本推断 | M5 贝叶斯层次模型 | 个体反应规范；10 只鸟下的稳健推断 |
| 稳健与异质性 | M6 双重机器学习 + 因果森林 | 混杂函数形式误设时效应是否仍在；效应随气温等如何变化 |
| 去向 | M7 积分步选择分析 | 转移去哪里 |
| 状态视角 | M8 混合 HMM | 潜在状态框架下结论是否一致 |
| 探索 | M9 位置—尺度模型 | 月光是否改变夜间位移的变异性 |

**结论规则（预先写定）：** 主结论需要 M1 与 M2 方向一致、阴性对照无效应、规格曲线中 ≥80% 的设定同号（第 6 节）。

## 1. 预先定义的效应量

效应量先于模型定义，模型只是估计它们的工具。

| 编号 | 效应量 | 定义 | 对应假设 |
| --- | --- | --- | --- |
| E1（主） | 即时光照效应 | 同一鸟夜内，有效月光 `moon_lit` 每增加 0.1 时，2 h 段发生≥1 km 转移的条件优势比 | H1 |
| E2 | 时机交互 | E1 在傍晚段（太阳时 18—22）与后半夜段（0—4）之差；按盈月/亏月分层 | H1 |
| E3 | 剂量—反应 | 转移概率随月亮高度、照亮比例、云量的非线性响应面 | H1 |
| E4 | 首次转移风险 | 月亮在天对"入夜后首次转移"风险率的影响 | H3 |
| E5 | 去向 | 月光与"步终点到当天白天活动中心距离"的交互 | H3 |
| E6 | 条件依赖 | E1 随夜间气温的变化 | H2 |
| E7 | 个体差异 | E1 的个体间标准差（只估计，不检验） | — |
| E8（探索） | 变异性 | 月光对夜间位移残差离散度的影响 | — |

**H1′（月相周期，非光照）的检验方式：** 模型同时放入 `illum`（月面照亮比例，代表月相）和 `moon_lit`（只有月亮在天才不为零）。H1 预测 `moon_lit` 有效应；H1′ 预测只有 `illum` 有效应。夜内模型 M2 中 `illum` 在同一夜内几乎不变，被分层吸收，因此 M2 只识别 `moon_lit`。

## 3. 因果结构与识别

```text
天文位置（外生） ──> 月亮在天 × 照亮比例 ──> 当时的地面月光 ──> 转移
                                                  ^
云量 ─────────────────────────────────────────────┘
日期/季节 ──> 月相、日长、气温、节庆、人类活动 ──> 转移
夜内时刻 ──> 月亮是否在天（随月相变化） ；夜内时刻 ──> 转移
个体、越冬地、放飞期 ──> 转移基线
```

- **夜内识别：** 以鸟夜为层（M2）或加入鸟夜随机效应（M1），吸收日期、节庆、越冬地、个体状态等夜级混杂（固定效应思路见 Larsen et al. 2019；结构因果框架见 Arif & MacNeil 2023）。
- **必须调整的变量：** 夜内时刻。月亮是否在天与夜内时刻相关，而转移本身也有夜内节律。
- **阴性对照（Lipsitch et al. 2010）：**
    1. 阴性对照暴露：白天段的"月亮在天"（白天月光无意义）。
    2. 安慰剂暴露：把每个段的时间平移 k 天（k 在 7—22 天内随机，避开整朔望月）后重算月亮变量。重复 1,000 次得到零分布，同时保留轨迹自身的时间自相关。
    3. 节庆敏感性：剔除春节 ±7 天（春节在新月，烟花可能使鸟夜间惊飞，见 Shamoun-Baranes et al. 2011）。

## 4. 模型组合：为什么用这些模型

总原则：**模型新颖本身不是创新点。** 每个模型放松一个不同的假设，用来回答"结论是否依赖某个建模选择"。新颖性按"在雁类或运动生态 GPS 研究中的使用频率"粗略评为低、中、高。

### M0 基准：鸟夜二项 GLMM（复现 WP3）

- **形式：** 鸟夜内≥1 km 段数 / 有效段数 ~ 月光指数 + 协变量 + (1|鸟)，β-二项。
- **理由：** 衔接已有结果。G1 门槛就用它，在剔除 H 系列和放飞期后重估。
- **新颖性：** 低。**角色：** 衔接与门槛。

### M1 段级层次 GLMM（主估计）

```r
library(glmmTMB)
m1 <- glmmTMB(
  y ~ moon_lit * part + moon_lit:cloud + illum + cloud + temp_c + wind_ms + precip +
      splines::ns(hrs_since_dusk, 3) + (1 | bird) + (1 | bird:night_id),
  family = binomial, data = seg)
```

- **理由：** 用到全部 334 个事件；能同时估计 E1、E2 和云量调节；`illum` 与 `moon_lit` 并列，直接对比 H1 与 H1′。
- **识别假设：** 鸟夜随机效应与暴露不相关；样条足以刻画夜内节律。
- **风险：** 10 只鸟的随机截距方差估计不稳；时间自相关（加 `ar1(time + 0 | bird:night_id)` 作敏感性）。
- **新颖性：** 低。**角色：** 主估计。

### M2 鸟夜分层条件 logistic（主识别）

```r
library(survival)
m2 <- clogit(
  y ~ moon_lit * part + moon_lit:cloud + temp_c + wind_ms + precip +
      strata(night_id) + cluster(bird),
  data = seg, method = "efron")
```

- **理由：** 每个鸟夜自成一层，所有夜级混杂（日期、月相、节庆、越冬地、个体当晚状态）全部被吸收，只剩夜内月亮升落带来的变异。这是本研究"自然实验"最直接的实现。
- **识别假设：** 同一夜内，除月亮位置外，没有与月亮升落同步变化的其他因素（夜内时刻已调整）。
- **风险：** 只用 158 个信息层、197 个事件，区间会比 M1 宽；无法估计 `illum` 主效应（这正是设计目的）。
- **新颖性：** 中。固定效应式的夜内设计在动物运动研究中少见。**角色：** 主识别。

### M3 离散时间风险模型（主过程模型）

```r
# risk：每个鸟夜从入夜到首次转移（含）的 2 h 区间，event = 该区间是否首次转移
m3 <- glmmTMB(
  event ~ moon_lit * early + illum + cloud + temp_c + wind_ms + precip +
          factor(interval) + (1 | bird),
  family = binomial(link = "cloglog"), data = risk)
```

- **理由：** "月光是否推迟归宿或提前离宿"本质上是**发生时刻**问题。离散时间风险模型（Allison 1982）天然处理 2 h 区间删失，并允许月亮状态在夜内随时间变化。cloglog 链接使系数可解释为风险比。
- **识别假设：** 比例风险（用 `moon_lit × early` 检验时机是否改变效应）；首次事件后不再进入风险集。
- **风险：** 只用每夜第一次转移，信息少于 M1；与 M1 的结论应一致而非独立。
- **新颖性：** 中—高。GPS 雁类研究多比较位移量，很少直接建模时刻。**角色：** 主过程模型（E4）。

### M4 层次广义可加模型（剂量—反应）

```r
library(mgcv)
m4 <- bam(
  y ~ part + s(hrs_since_dusk, k = 6) +
      te(moon_alt, illum, k = c(5, 5), by = part) + s(cloud, k = 4) + s(temp_c, k = 4) +
      s(moon_lit, bird, bs = "fs", k = 4) + s(bird, bs = "re") + s(night_id, bs = "re"),
  family = binomial, data = seg, discrete = TRUE, method = "fREML")
```

- **理由：** "月亮在天"是二分化简化。光照效应可能存在阈值（例如只有高度和照亮比例都足够时才起作用）。张量积曲面直接画出"月亮高度 × 照亮比例"上的响应，并按夜内时段分开。个体平滑项（`bs = "fs"`）是层次 GAM 的 GI 结构（Pedersen et al. 2019）。
- **识别假设：** 与 M1 相同，但不假设线性。
- **风险：** 334 个事件下曲面自由度要受控；只作估计与图示，不做逐点显著性判断。
- **新颖性：** 中。**角色：** E3 剂量—反应与主图。

### M5 贝叶斯层次模型（个体与小样本推断）

```r
library(brms)
m5 <- brm(
  y ~ moon_lit * part + moon_lit:cloud + illum + cloud + temp_c + wind_ms + precip +
      s(hrs_since_dusk, k = 4) + (1 + moon_lit | bird) + (1 | bird:night_id),
  family = bernoulli(), data = seg, backend = "cmdstanr", chains = 4, iter = 4000,
  prior = c(prior(normal(0, 1), class = b),
            prior(exponential(2), class = sd),
            prior(lkj(2), class = cor)))
```

- **理由：** 只有 10 个个体时，频率学派的随机效应方差常估计为 0 或不收敛；弱信息先验给出稳定的部分合并。随机斜率给出每只鸟的月光反应规范（Dingemanse et al. 2010），并附完整后验区间（Bürkner 2017）。
- **识别假设：** 与 M1 相同；先验对结论的影响用先验敏感性检验。
- **风险：** 斜率标准差的后验会很宽（Martin et al. 2011），只报告估计，不判定"个体差异是否存在"。
- **新颖性：** 中。**角色：** E7 与 E2 的贝叶斯推断。

### M6 双重机器学习与因果森林（稳健性与异质性）

```r
library(DoubleML); library(mlr3); library(mlr3learners)
dat <- DoubleMLClusterData$new(
  seg_df, y_col = "y", d_cols = "moon_lit",
  x_cols = c("illum", "cloud", "temp_c", "wind_ms", "precip", "hrs_since_dusk", "doy", "season"),
  cluster_cols = c("bird", "lunar_cycle"))
dml <- DoubleMLPLR$new(dat, ml_l = lrn("regr.ranger"), ml_m = lrn("regr.ranger"), n_folds = 5)
dml$fit()

library(grf)
cf <- causal_forest(
  X = as.matrix(seg[, c("illum", "cloud", "temp_c", "wind_ms", "hrs_since_dusk", "doy")]),
  Y = seg$y, W = seg$moon_up, clusters = seg$lunar_cycle, num.trees = 4000)
average_treatment_effect(cf)
best_linear_projection(cf, seg[, c("temp_c", "hrs_since_dusk")])
```

- **理由：** M1—M5 都假设协变量的函数形式（线性或平滑）。如果天气、日期、夜内时刻与月光的关系被设错，效应可能有偏。双重机器学习用机器学习灵活拟合这些混杂，再在正交化残差上估计月光效应（Chernozhukov et al. 2018；Bach et al. 2024）。因果森林在不预设交互项的情况下，估计月光效应随气温、夜内时刻如何变化（Wager & Athey 2018；Athey et al. 2019），可以替代逐个检验交互项，减少多重比较。
- **识别假设：** 条件可忽略性（给定协变量后月亮状态"如同随机"，在天文暴露下较合理）；重叠性（各夜内时刻都有月亮在天与不在天的段）。按个体与朔望月双向聚类做交叉拟合。
- **风险：** 只有 10 只鸟和约 14 个朔望月，异质性估计噪声大；因果森林结果只作探索。
- **新颖性：** 高。在动物运动生态中使用很少。**角色：** E1 的稳健性检验；E6 的探索性异质性分析。

### M7 积分步选择分析（去向）

```r
library(amt)
ssf <- trk |> steps_by_burst() |> random_steps(n_control = 20) |>
  extract_covariates(...) |>
  mutate(log_sl = log(sl_ + 0.01))
m7 <- glmmTMB(
  case_ ~ d_daycentre_end + d_daycentre_end:moon_lit + log_sl + log_sl:moon_lit + sl_ +
          (1 | step_id) + (0 + d_daycentre_end | bird),
  family = poisson, data = ssf,
  map = list(theta = factor(c(NA, 1))), start = list(theta = c(log(1e3), 0)))
```

- **理由：** M1—M6 只回答"是否转移"。iSSA 同时估计移动核（步长分布随月光的变化）和去向选择（终点是否远离白天活动中心），对应 H3（Avgar et al. 2016）。用泊松技巧拟合带个体随机斜率的条件模型（Muff et al. 2020），工具用 amt（Signer et al. 2019）。
- **识别假设：** 可用步由经验步长和转角分布正确生成；2 h 尺度上的可用范围合理。
- **风险：** 白天活动中心由白天定位计算，不是真实觅食地；生境层（CLCD 年度数据）对洪泛区水线变化不敏感，因此主分析只用距离变量。
- **新颖性：** 中。iSSA 很常见，但用月光调节移动核的不多。**角色：** E5。

### M8 混合隐马尔可夫模型（状态视角的稳健性）

```r
library(momentuHMM)
hmm <- fitHMM(
  data = prep, nbStates = 2, dist = list(step = "gamma"),
  Par0 = list(step = c(0.1, 2, 0.1, 2, 0.3, 0.01)),   # 均值、标准差、零质量
  formula = ~ moon_lit * part + temp_c, mixtures = 2)
```

- **理由：** 用潜在状态与状态持续性的框架重估"月光是否提高进入转移状态的概率"（McClintock & Michelot 2018）。`mixtures = 2` 给转移概率加离散随机效应，近似个体异质性（混合 HMM 思路见 McKellar et al. 2015）。
- **识别假设：** 一阶马尔可夫；2 h 步长可以分出状态。
- **风险：** 2 h 下转角几乎无信息，状态基本等于位移分级（Postlethwaite & Dennis 2013）；不把状态解释为行为（Glennie et al. 2023）。
- **新颖性：** 低—中。**角色：** 稳健性。

### M9 位置—尺度模型（探索）

```r
m9 <- brm(
  bf(log1p_d ~ moon_lit * part + temp_c + (1 | bird),
     sigma ~ moon_lit + (1 | bird)),
  family = student(), data = seg_night)
```

- **理由：** 月光可能不改变平均位移，而改变位移的可变性，即行为可预测性（Mitchell et al. 2016；Hertel et al. 2021）。
- **风险：** 位移有 GPS 误差下限和重尾；只作探索。
- **新颖性：** 高。**角色：** E8，明确标为探索性。

### 考虑过但不采用

| 模型 | 不采用的理由 |
| --- | --- |
| 连续时间离散空间模型（Hanks et al. 2015） | 适合不规则采样和栅格景观；本数据为规则 2 h 定位，且没有可靠的夜间栅格协变量，收益小、计算量大 |
| 深度学习序列模型（LSTM 等） | 10 只鸟、334 个事件不足以训练；不可解释，无法对应预先定义的效应量 |
| 空间—时间随机场（INLA 等） | 研究问题不是空间分布；夜内识别已处理主要混杂 |

## 5. 模型比较框架

模型比较分三类，目的不同，不能混为一谈。

### 5.1 识别三角验证（主结论依据）

同一效应量 E1、E2 在 M1、M2、M5、M6 中分别估计，汇总成一张一致性表：

| 效应量 | M1 | M2 | M5 | M6 | 阴性对照 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | OR [CI] | OR [CI] | 后验 OR [CrI]，P(OR>1) | θ [CI] | 安慰剂 / 白天段 | 一致 / 部分 / 不一致 |
| E2 | … | … | … | — | — | … |

各模型放松的假设不同：M2 去掉夜级混杂，M5 处理小样本随机效应，M6 去掉函数形式假设。方向一致时，结论不依赖单一建模选择。

### 5.2 预测比较（回答"月光信息有没有预测价值"）

- **交叉验证：** 留一鸟（10 折）与留一朔望月（约 14 折）两种分组交叉验证。
- **指标：** 对数得分、Brier 分数、AUC、校准斜率与截距。
- **贝叶斯模型：** PSIS-LOO 加分组 K 折（Vehtari et al. 2017）；用 stacking 权重（Yao et al. 2018）比较"无月光""只有月相""月光加时机"三种 M5 变体。
- **解读：** WP3 已显示月光没有改善留一鸟预测。预测比较只用来如实报告预测价值，不作为月光效应是否存在的判据。

### 5.3 规格曲线 / 多宇宙分析（回答"结论是否依赖分析选择"）

列出所有合理的分析选择，全部跑一遍（Steegen et al. 2016；Simonsohn et al. 2020）：

| 选择 | 取值 |
| --- | --- |
| 位移阈值 | 0.5 / 1 / 2 km |
| 放飞期剔除 | 3 / 7 / 14 天 |
| 月光暴露 | `moon_lit` / `moon_up_frac` / 月亮高度 > 5° |
| 夜内分段 | 三段 / 入夜后小时数连续 |
| H 系列 | 剔除 / 纳入 |
| 春节窗口 | 保留 / 剔除 |
| 模型 | M1 / M2 / M5 |

共 3×3×3×2×2×2×3 = 648 种设定。报告估计值分布、同号比例，以及用 3.2 节安慰剂平移得到的联合零分布。

### 5.4 多重比较控制

- **门控顺序：** 先检验 E1；E1 成立后才检验 E2；然后依次是 E4、E5、E6。
- **次要效应量族内：** 用 Holm 校正。
- **探索性分析：** E7、E8 和因果森林异质性明确标为探索，不报告 p 值。

## 6. 预先写定的判定规则

| 结论 | 条件 |
| --- | --- |
| **支持 H1（即时光照）** | M1 中 `moon_lit` 的 OR > 1，且按朔望月分块 Bootstrap 的 95% 区间不含 1；M2 方向相同；两个阴性对照区间含 1 且点估计小于 E1 的一半；规格曲线同号比例 ≥ 80% |
| **支持时机作用** | E2 在 M1 或 M5 中符合预测方向（盈月作用于傍晚段、亏月作用于后半夜段），区间不含 0 或后验概率 > 0.95；M2 方向相同 |
| **支持 H1′（月相周期）** | `illum` 有效应，`moon_lit` 区间上限小于 E1 预设最小关注效应（OR 1.15 / 0.1 单位） |
| **不确定** | 以上都不满足；报告效应量与区间，不写"无效应" |
| **支持 H2** | E6 中月光效应随气温降低而增强，Holm 校正后显著 |
| **支持 H3** | E4 中月光提高傍晚首次转移风险，且 E5 中月光增强远离白天活动中心的选择 |

## 7. 功效评估（P1 之后、P3 之前完成）

**粗略估算（未考虑聚类，偏乐观）：**

- M1 用 334 个事件、暴露比例约 0.47 时，log OR 的标准误约 0.11，80% 功效的最小可检测效应约为 OR 1.36（二分暴露）。
- M2 只有 197 个信息事件，最小可检测效应约为 OR 1.49。
- E2 交互项需要约 4 倍样本才能检测同等大小的效应。**时机交互是本方案功效最弱的环节。**

**正式评估：** 在不含月光项的 M1 拟合值基础上，模拟 OR = 1.25、1.5、2.0 三种情形，各 500 次，计算 E1、E2 在 M1、M2 中的功效（simr 或自写模拟，Green & MacLeod 2016）。

**结果处理：** 若 E2 功效 < 50%，在预案中把 E2 降为"估计"，不作检验；论文主线落在 E1 与 E4。

## 10. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 剔除 H 系列和放飞期后，WP3 效应消失 | G1 门槛；不通过则启用备选方向 D3 |
| E2 时机交互功效不足 | 预先把 E2 降为估计；主线落在 E1 与 E4 |
| 模型结论不一致 | 按 5.1 节如实报告不一致，并分析是哪个假设导致的差异 |
| 机器学习模型过拟合、聚类处理不当 | 按个体与朔望月双向聚类交叉拟合；只作稳健性与探索 |
| 多模型带来"挑选"嫌疑 | 本文件定稿后打标签；所有模型结果全部报告 |
| 数据授权与已发表研究重叠 | P0 向数据方确认；论文中说明与 Si et al. (2018, 2020) 的关系 |
